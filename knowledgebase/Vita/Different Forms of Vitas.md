We at Monocircuit Vita, offer different types of [[Vita|Vitas]] on our platform.

### How to Represent Different Types of [[Vita|Vitas]] in the Codebase?
To keep it structural we want to do the following naming them like this:
- `VitaDynamic`
- `VitaStatic`
would have the benefit of the same beginning word, which makes grouping easier. But using the plural for database tables becomes quite difficult. Thus the other option would be to use somelike this:
- `DynamicVita`
- `StaticVita`
which would make using the plural way more intuitive like this:
- `DynamicVitas`
- `StaticVitas`
