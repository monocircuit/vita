A [[ChronicleKnot]] is a point on the [[DynamicVita]]. Multiple [[ChronicleKnot]] define a [[ChroniclePath]] in the [[DynamicVita]]. The point is defined by a ``date``, which gives the renderer information about the `x-Coordinate`, and the `layer` tells the `y-Coordinate`.
# Schema
```
{
	date: Date;
	layer: number;
}
```
