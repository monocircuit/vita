A [[ChroniclePathKnot]] is a point on the [[Dynamic Vita]]. Multiple [[ChroniclePathKnot]] define a [[ChroniclePath]] in the [[Dynamic Vita]]. The point is defined by a ``date``, which gives the renderer information about the `x-Coordinate`, and the `layer` tells the `y-Coordinate`.
# Schema
```
{
	date: Date;
	layer: number;
}
```
